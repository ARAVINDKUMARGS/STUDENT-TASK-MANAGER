# Project Screenshots & Visual Showcase

This directory stores high-resolution screenshots of the **StudyFlow - Student Task & Productivity Manager** application across different viewport sizes and application states.

## Recommended Screenshots to Place Here:

1. **`dashboard-light.png`**:
   - Full desktop view showing the main dashboard in Light Mode, key metrics, productivity rings, and task list.
2. **`dashboard-dark.png`**:
   - Full desktop view displaying Dark Mode with glowing neon status badges and dark theme contrast.
3. **`task-modal-create.png`**:
   - The interactive task creation modal with real-time form validation, subject select, priority badges, and estimated Pomodoro count.
4. **`pomodoro-focus-timer.png`**:
   - The integrated Pomodoro Focus Timer in active state with circular SVG countdown and task linkage.
5. **`mobile-responsive.png`**:

   - The dynamic search filter in action, displaying category chips, status tabs, and real-time query results.
